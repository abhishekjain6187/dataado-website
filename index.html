Data Catalog

Understand a database you've never seen

Handed an unfamiliar clinical or ERP system? Dataado scans it and tells you where the demographics, orders, results, documents, flags and code tables actually live — even when the tables are named T_47 and the columns C1…C7. The same map comes back whether the source is SQL Server or Oracle.

Classifies columns by their data, not their names — SSNs, emails, file paths, flags and documents are recognised by value shape.
Finds file-pointer columns Dataado can then act on — locate the pointer, fetch what it points at.
Aggregates-only sampling — it learns "96% SSN-shaped" without ever reading a single value. Shape travels; content never does.
Turns discovery into a ready-to-run extraction query — audit columns dropped, code columns decoded against their lookup, soft-deleted rows filtered out.
Learns your corrections — confirm or fix a finding once and it sticks across every re-scan, kept per-tenant and never shared.
AI co-pilot

AI that never leaves your network

Dataado's AI is an opt-in add-on that runs entirely on a model server you host. Prompts carry run logs, schemas and connection codes — so they never touch a third-party API.

Explain this failure — a grounded, specific diagnosis of a failed run, assembled from its real config, outputs and logs.
Two switches, both required — a platform master switch and a per-tenant entitlement. Off by default; fails by disappearing, never by breaking.
Plug-and-play — point it at your own endpoint and model from the admin page; no code, no restart.
